
# JLSS Control Panel Data Entry Guide

**Control Panel URL:** https://control.janloksewa.com

This guide provides step-by-step instructions for adding and managing data for all content types in the JLSS control panel. Each section below corresponds to a specific content type or control panel option available in your system.

---

## 1. About (Single Type)
- **Fields:** About, Mission, Vision, Email, Phone
- **How to Add/Edit:**
    - Go to "About" in the sidebar of the control panel.
    - Fill in or update the text fields for About, Mission, Vision, Email, and Phone.
    - Save your changes.

## 2. Programs
- **Fields:** Slug, Title, Subtitle, Description, Achievements, Beneficiaries, Focus Areas, Impact Metrics
- **How to Add:**
    - Go to "Programs" in the control panel.
    - Click "Create new entry".
    - Fill in all required fields. Use JSON format for Achievements, Beneficiaries, Focus Areas, and Impact Metrics.
    - Save and publish.

## 3. Stories
- **Fields:** Slug, Title, Subtitle, Category (education, health, environment, general), Impact, Content
- **How to Add:**
    - Go to "Stories" in the control panel.
    - Click "Create new entry".
    - Fill in the fields, select a category, and add content.
    - Save and publish.

## 4. Impact Cards
- **Fields:** Number, Name, Icon, Description, Order
- **How to Add:**
    - Go to "Impact Cards" in the control panel.
    - Click "Create new entry".
    - Fill in the number, name, icon, and description.
    - Set the display order if needed.
    - Save and publish.

## 5. Impact Stats
- **Fields:** Label, Value, Icon, Order
- **How to Add:**
    - Go to "Impact Stats" in the control panel.
    - Click "Create new entry".
    - Fill in the label, value, and icon.
    - Set the order if needed.
    - Save and publish.

## 6. Growth Metrics
- **Fields:** Year, Percentage, Label, Description, Metric Type (beneficiaries, programs, reach, etc.)
- **How to Add:**
    - Go to "Growth Metrics" in the control panel.
    - Click "Create new entry".
    - Fill in the year, percentage, label, and description.
    - Select the metric type.
    - Save and publish.

## 7. Financial Years
- **Fields:** Year, Total Funds, Active Programs, Beneficiaries, Order
- **How to Add:**
    - Go to "Financial Years" in the control panel.
    - Click "Create new entry".
    - Fill in all fields.
    - Save and publish.

## 8. Budget Allocations
- **Fields:** Category, Percentage, Financial Year, Order
- **How to Add:**
    - Go to "Budget Allocations" in the control panel.
    - Click "Create new entry".
    - Fill in the category, percentage, and optionally the financial year.
    - Set the order if needed.
    - Save and publish.

## 9. Annual Reports
- **Fields:** Name, Icon, Description, Report Type (annual-report, audit-report, etc.), File
- **How to Add:**
    - Go to "Annual Reports" in the control panel.
    - Click "Create new entry".
    - Fill in the name, icon, description, and select the report type.
    - Upload the report file.
    - Save and publish.

## 10. Certifications

- **How to Add:**
    - Go to "Certifications" in the control panel.

## 11. Core Values

    - Go to "Core Values" in the control panel.

## 15. Global Settings (Single Type)
- **Fields:** Site Name, Site Description, Social Media Links, Contact Info, Contact Reasons, Volunteer Roles, Volunteer Benefits, Hero Features, Donation Reasons
- **How to Edit:**
    - Go to "Global Settings" in the control panel.
    - Update the fields as needed (JSON for complex fields).
    - Save your changes.

## 16. Hero Setting (Single Type)
- **Fields:** Video URL, Heading 1, Heading 2, Description
- **How to Edit:**
    - Go to "Hero Setting" in the control panel.
    - Update the video URL, headings, and description.
    - Save your changes.

## 17. Hero Video (Single Type)
- **Fields:** Video URL, Poster URL, Enabled
- **How to Edit:**
    - Go to "Hero Video" in the control panel.
    - Update the video and poster URLs, and enable/disable as needed.
    - Save your changes.

## 18. Contact Messages (Read Only)
- **Fields:** Name, Email, Subject, Message, Read
- **How to View:**
    - Go to "Contact Messages" in the control panel to view messages submitted via the contact form.

## 19. Volunteer Requests (Read Only)
- **Fields:** Name, Email, Phone, Experience, Interests, Message
- **How to View:**

## 20. Donation Records (Read Only)
- **Fields:** Name, Email, Mobile, Amount, Program, Transaction ID, Payment Status
- **How to View:**
    - Go to "Donation Records" in the control panel to view donation submissions and statuses.
